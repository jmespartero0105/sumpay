# Lottie assets

Drop the following `.json` Lottie animation files here to enable full motion:

- `emergency_pulse.json`
- `mesh_network.json`
- `empty_state.json`
- `success_check.json`

If a file is missing, the app automatically shows an animated icon fallback
(see `lib/core/widgets/lottie_placeholder.dart`), so the prototype runs either
way. Free Lottie files are available at https://lottiefiles.com.
